     ./rebuild_fixed_services.sh

┌──────────────────────────────────────────────────────────────┐
│ 🔧 COMMON FIXES                                               │
└──────────────────────────────────────────────────────────────┘

  Lỗi 1: 404 Not Found
  ─────────────────────
  → Check API Gateway logs
  → Verify routing in APIGateway/main.py
  
  Lỗi 2: CORS Error
  ─────────────────────
  → Rebuild API Gateway (có CORS middleware)
  → Clear browser cache (Ctrl+Shift+R)
  
  Lỗi 3: SePay không redirect
  ─────────────────────
  → Check BACKEND_PUBLIC_URL trong .env
  → Verify ngrok URL còn hoạt động
  → Check logs: docker-compose logs billing_api | grep SePay
  
  Lỗi 4: Manager không thấy facilities
  ─────────────────────
  → Check user role trong database
  → Check facility_managers table
  
  Lỗi 5: Ngrok warning page
  ─────────────────────
  → Verify header "ngrok-skip-browser-warning" được thêm
  → Check apiClient.js và payment_handler.js

┌──────────────────────────────────────────────────────────────┐
│ 💡 PRO TIPS                                                   │
└──────────────────────────────────────────────────────────────┘

  1. Luôn kiểm tra logs trước khi rebuild:
     docker-compose logs -f apigateway billing_api
  
  2. Clear browser cache khi test frontend:
     Ctrl+Shift+R (Chrome) hoặc Cmd+Shift+R (Mac)
  
  3. Ngrok URL thay đổi mỗi khi restart:
     Tạo alias để auto-update:
     alias update-ngrok='./scripts/update_ngrok_url.sh'
  
  4. Monitor real-time logs:
     docker-compose logs -f --tail=100 apigateway billing_api
  
  5. Test API trực tiếp với curl trước khi test từ UI
  
  6. Use Chrome DevTools Network tab để debug requests
